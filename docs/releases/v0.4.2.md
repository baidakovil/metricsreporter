# Release v0.4.2 — 2026-03-29

Highlights

- Fixed coverage HTML linking when `coverageHtmlDir` is an HTTP/HTTPS URL. Links in the generated HTML dashboard now point directly to ReportGenerator pages served over HTTP.
- Updated `HtmlReportGenerator` and `CoverageLinkBuilder` behavior to accept HTTP(S) paths and generate `href` attributes accordingly.
- Minor test updates to align header text and avoid hard-coded assembly version checks.

What changed (technical)

- `MetricsReporter.Services.MetricsReporterApplication`: pass `coverageHtmlDir` into `HtmlReportGenerator.Generate` for HTML-only generation mode.
- `MetricsReporter.Rendering.CoverageLinkBuilder`: treat HTTP and HTTPS schemes as valid coverage sources; return encoded URL for anchors.
- `MetricsReporter.Configuration.ConfigurationWarningEvaluator`: treat HTTP(s) `coverageHtmlDir` values as existing to avoid spurious warnings.
- `MetricsReporter.Tests.Rendering.HtmlReportGeneratorTests`: loosened tool-version assertion and updated header expectation.

Artifacts

- NuGet packages created and placed in `artifacts/nuget/`.

Notes for maintainers

- Tag `v0.4.2` has been pushed to the remote and is available at https://github.com/baidakovil/metricsreporter/releases/tag/v0.4.2
- CI should pick up this tag for release workflows if configured.
