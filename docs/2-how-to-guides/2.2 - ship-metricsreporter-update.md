## How-to: Ship a MetricsReporter Release

Use this guide when you have finished changes and want to publish a new version to NuGet.org.

### Prerequisites

- .NET 8 SDK with `dotnet` on `PATH`.
- A NuGet.org API key with push rights to the `MetricsReporter.Tool` and `MetricsReporter` packages.

### Step 1: Bump the version

Edit `Directory.Build.props` in the repo root and increase `<Version>` (at least the patch segment). Reusing an existing semantic version causes NuGet to serve cached packages.

```xml
<Version>0.4.2</Version>  <!-- was 0.4.1 -->
```

### Step 2: Update `CHANGELOG.md`

Add a section at the top of `CHANGELOG.md` following the Keep a Changelog format. Include a reference link at the bottom of the file pointing to the new tag:

```markdown
## [0.4.2] - YYYY-MM-DD

### Fixed
- ...

[0.4.2]: https://github.com/baidakovil/metricsreporter/releases/tag/v0.4.2
```

### Step 3: Build and test

```powershell
dotnet build --no-incremental
dotnet test
```

Ensure both pass cleanly before packing.

### Step 4: Pack

```powershell
dotnet pack MetricsReporter/MetricsReporter.csproj -c Release -o ./artifacts
dotnet pack MetricsReporter.Tool/MetricsReporter.Tool.csproj -c Release -o ./artifacts
```

### Step 5: Push to NuGet.org

```powershell
dotnet nuget push artifacts/MetricsReporter.<version>.nupkg `
  --api-key <YOUR_API_KEY> --source https://api.nuget.org/v3/index.json
dotnet nuget push artifacts/MetricsReporter.Tool.<version>.nupkg `
  --api-key <YOUR_API_KEY> --source https://api.nuget.org/v3/index.json
```

### Step 6: Create a GitHub Release

1. Commit and push the version bump and CHANGELOG.
2. Tag the commit: `git tag v<version> && git push origin v<version>`.
3. On GitHub, go to **Releases → Draft a new release** → select the tag → paste the relevant CHANGELOG section as release notes.

### Step 7: Update the local tool manifest (optional)

If you use the local manifest (`.config/dotnet-tools.json`) inside this repo for dogfooding, update the pinned version:

```powershell
dotnet tool update metricsreporter.tool --version <new-version>
```
